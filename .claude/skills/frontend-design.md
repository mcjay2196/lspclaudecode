# Frontend Design Skill

This skill enables creation of distinctive, production-grade frontend interfaces that prioritize high design quality and avoid generic aesthetics.

## Key Principles

**Design Philosophy**: Before coding, establish a bold aesthetic direction by understanding purpose, selecting a distinctive tone, and identifying what makes the interface memorable.

**Visual Execution**: The approach emphasizes:
- Distinctive typography choices beyond common defaults
- Cohesive color systems with dominant hues and sharp accents
- Strategic animation focused on high-impact moments
- Unexpected spatial composition using asymmetry and overlap
- Contextual visual details that build atmosphere

## Critical Guidance

Avoid "generic AI-generated aesthetics" including overused font families and predictable layout patterns. Interpret creatively and make unexpected choices that feel genuinely designed for the context.

Implementation complexity should match the aesthetic vision — maximalist designs require elaborate code with extensive effects, while refined minimalist work demands restraint and precision in spacing and typography.

Treat each project as unique, encouraging variation across different solutions rather than convergence on common design defaults.
